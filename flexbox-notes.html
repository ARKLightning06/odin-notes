Notes on Flexbox

Intro

Flexbox arranges things horizontally or vertically and flexes, i.e. grows/shrinks, to fit a space.

Two main parts:

  • Flex container: an element containing flex items... contains display: flex in it
  • Flex item: an item in a flex container

An element can be an item and a container

Grow Shrink Basis

There are three main properties of flex:

  1. flex-grow: Determines how much extra space it will get
  2. flex-shrink: Determines how much it's willing to shrink relative to others
  3. flex-basis: Determines the original size

There are many shorthands for all these:

  • flex: none = flex: 0, 0, auto
  • flex: auto = flex: 1, 1, auto
  • flex: n = flex: n, 1, 0

Axes

Two axes: horizontal and vertical. The default is horizontal, or row, but can also do vertical, or column

Use flex-direction: row/column to change

Note that you have to specify basis to auto instead of using the shorthand flex: 1 with column direction sometimes, becasue a container will default to the size of its content, and if basis is 0 it might collapse

Also, changing flex-direction changes flex-basis: by default, with direction: row, flex-basis refers to width. With flex-direction: column, it refers to height

You can also change the order: flex-direction: row-reverse will order things in reverse order, same with column-reverse. You can also specify order with order: n

Alignment

Can arrange more interestingly

  • On the main axis: put justify-content: space-between in flex-container class to justify content with space between items. Many other options:
    • Position: flex-start | center | flex-end
      • used for both justify-content and align-items
    • Spacing: space-between | space-around | space-evenly
      • used only for justify-content
  • On the cross axis: put align-items: space-between in flex-container class to manipulate cross-axis... except really just manipulating all the individual items, hence the align-items. There's also an align-self attribute to put on items rather than containers, align-items is like doing that to all of them
    • As mentioned, can align position: flex-start, center, and flex-end. However, can't align spacing, because it's affecting the individual items, and you can only really space out a group of items, not each item individually
    • Additionally, there's stretch | baseline which stretch along the cross axis or set that attribute to baseline
  • gap: npx will add a gap of n pixels, which can be useful for various things

Hypothetical size: what an item would be in a 'perfect world.' In reality size gets messed up, with flex it's flexible so it can grow or shrink, in flow, the default, it's fixed

Can also use margins to align elements to the left or right with margin-left and margin-right set to auto

flex-wrap: wrap will allow items to wrap, or go down to multiple lines basically

The possibility of multiple rows / columns also allows for the align-content call which allows us to align the rows basically when there are multiple
