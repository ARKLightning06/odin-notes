# odin-notes
Welcome! This is a simple repo for my notes as I'm learning full stack development from [The Odin Project](https://www.theodinproject.com/).

## About Odin
The Odin Project provides a free open source coding curriculum that can be taken entirely online. It teaches everything from the basics of html, css, and javascript, to advanced tools for full stack development like NodeJS, Ruby on Rails, and React. 

Huge thanks to all the people who put together and maintain this curriculum!

## This Repo
This repo is my person version of the notes contained (in a much nicer format) in the Odin Project. I find writing down what I learn helpful, and doing so with html not only records my notes but also gives me any easy stage to practice the skills as I learn them.

Besides notes, I've also included several minor projects in this repo. As of writing this README, that includes [a functional calculator](https://arklightning06.github.io/odin-notes/calculator.html), [rock paper scissors game](https://arklightning06.github.io/odin-notes/javascript-notes.html#rochambeau-v1), [etch-o-sketch](https://arklightning06.github.io/odin-notes/sketch.html), and a few miscellaneous smaller projects. 

## Usage
As of writing this README, I'm still in the process of learning TOP (The Odin Project), so more and more will be added to this repo. Anyone is free to look through it as they wish, but these notes are made with the purpose of supplementing my own learning, not for helping others. If anyone wants to seriously learn this themselves, I highly recommend taking The Odin Project. This repo could theoretically also be used as a sort of reference or reminder or summary sheet of the many lessons of web dev, but again I'd recommend finding a better one actually intended to be used that way, there are many out there to choose from.
