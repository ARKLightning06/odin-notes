Some basic tags

Use the (angle brackets) tag to make paragraphs

Nesting and Indentation

We can nest elements within each other. Doing so creates a 'parent child' relationship where the nested elements are the children and the elements they are nested within are the parents.

When two elements are nested under the same parent, like these top two paragraphs, they are called siblings.

Links

Links are cool (see the image section for why, perhaps)

To create a link, use anchor elements, which use <a> to open and close. Within the first angle brackets, do a then href="your link here", which will ultimately desgnate something as a link.

You can link anything, not just other html documents. Videos, pdfs, images, whatever your heart desires.

If you want to open links in a new tab instead of changing the current tab, use target. Target specifies where the linked resource will be opened. By default it takes the _self value, to open in a new tab we use _blank. For example, this opens in a new tab.

There's also a rel parameter. The above example set it to "noreferrer", but you could also do "noopener."

  • "noopener" prevents the new tab from accessing the original page, which is apparently risky for phishing attacks and tabnabbing.
  • "noreferrer" is the same as noopener but also prevents certain details about the original page from being passed to the new page, as referrer information is not always desirable to share.

There are two general kinds of links we'll create:

  1. Absolute Links: links to pages on other websites. Include scheme://domain/path, and will always include scheme and domain. (for example, https://www.theodinproject.com/about).
  2. Relative Links: links to other pages within our own websites. We can have multiple html files in the same directory. If so, href="filename.html". But you could also put them inside directories under the one index is in, in which case it becomes href="dir/filename.html".

Images

Why are links so cool you asked?

Images exist! use <img> to create one, and src="whatever" to specify which image.

Sidenote: sometimes for images or maybe also relative links you want to go to a parent directory first then a child direction. In these cases, use ..

Alt attribute exists: after src, add in alt="alternative text for the image"

You can also specify height and width using height="some number" width="some number".
