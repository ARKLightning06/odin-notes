Notes on CSS (Cascading Style Sheets)

Basic Syntax

At the most basic level, CSS is made up of various rules, where each rule has a selector and a semicolon separates list of declarations, with each declaration having a property-value pair.

  • Selectors refer to the HTML elements to which CSS rules apply. Some examples:
    • Universal Selector: *
    • Type selectors (ex: div, p, h1, etc)

      • body {
       ...
      }

    • Class selectors (when declaring an html element you can specify a class), which are indicated with a period .

      • .tag {
       ...
      }

    • Id selectors (when declaring an html element you can specify an id, but elements can only have one id and they can have multiple classes), which are indicated with a hashtag #

      • #something {
       ...
      }

    • Grouping selectors: not a type, but a strategy. When assigning a declaration to a selector, can group multiple selectors together with commas
    • Chaining selectors: again, not a type but a strategy, can chain two or more selectors together (ex: .example.header instead of .example, .header) to specify that element must have both of those categories.
    • Combinator: four types, one is the descendant combinator, a single space between selectors indicates the first one must be a parent of the second one.
  • Properties are CSS properties to manipulate html styless.
    • color: sets an element's text's color (can take hex, rgb, or hsl)
    • background color: sets the background color of an element (can take hex, rgb, or hsl)
    • font family: determines what font an element uses, can be a single value or a list in which case it chooses the first one but if not available might default to the next one
    • font size: set size of font
    • font weight: affects boldness of text, if bolded
    • text-align: align text horizontally within an element, can change with center or left/right
    • image height and width: best to include in both html and css, as including it in html will reserve space for it on the page when it loads

Adding CSS to HTML

There are three ways:

  1. External CSS: create separate file for the CSS and link it inside an HTML's opening and closing head tags with a link element: <link rel="stylesheet" href="filename.css"> Pros: keeps HTML and CSS separated, meaning smaller cleaner html file, and only need to edit CSS in one place, great for websites with many pages that all share similar styles.
  2. Internal CSS: add the CSS within the HTML file itself. Add everything within a style tag within the head area. Decent for websites with only a single page, but can get pretty big.
  3. Inline CSS: not recommended, but can do it in the html itself by directly specifying style="color: whatever; background-color: etc;"

Cascades

Cascade in CSS is essentially a hierarchy of what gets chosen over what.

Specificity: how specific something is. Every type of selector has it's own level.

  1. id: most specific (of the three)
  2. class: second most specific (of the three)
  3. type: third most specific (of the three)

Note also that number of selectors can influence specificity: something with two classes is more specific than one class, but one id is more specific than two classes.

Not everything influences specificity, like combinators like decsendent / child etc.

Inheritance exists: certain attributes will descend down the inheritance, so all the children of something will inherit from descendents.

Generally, typography based properties are inherited and others are not, but it depends and you can check MDM (here's the example for color) on a case by case basis.

The Tiebreaker: should all else fail and two rules are equally specific, whichever was defined last 'wins.' This is known as rule order.

Inspector

The inspector exists and is kinda cool, lots of cool stuff to do with it...

  1. Open it: many ways, right click an element and say inspect, ctrl c, ctrl j for java script, ctrl i for last tab or something, f12
  2. Inspect: when it's open, you can see the html stuff
  3. Play around: the DOM, basically tree of stuff you can drag around, also can use the styles tab to adjust other stuff, lots of options
