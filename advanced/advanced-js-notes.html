Intermediate CSS Concepts

Default Styles

Default styles exist, but some people don't like them. There are reset sheets which basically reset defaults, they're optional and some devs like them some don't

Normalizers try to embrace the defaults and normalize them across browsers, while resets nuke them away completely to build everything from scratch. Hybrid is a mix of both

CSS Units

There are many different unit types for css

Unit Category Unit css name Unit Description
Absolute Units px pixels: pixel size doesn't change
in inches - don't use this
cm centimeters - don't use this
Relative Units em font size of an element - 4 em of a 16px font element would be 64px - better to use rem
rem font size of the root element (html/:root) - better to use then em
vh viewport height - 1vh is 1% of the viewport height
vw viewport width - 1vw is 1% of the viewport width

Font Families exist, you can import libraries or fonts with import statements and links and even self hosting, but it's still good to have backups

Other text styling includes text-style (like emphasis or italics), letter spacing, line height, text transform (upper/lowercase), text shadow, and ellipsis

Advanced Selectors

Can use selectors like space, +,>, ~, and also pseudo selectors

  • Space is descendent selector, so main div selects all divs under main
  • > is child selector, so main > div selects all divs directly under main (and none under those)
  • + is adjacent sibling selector, so .class2 + div selects all divs that are adjacent to .class2... presumably .class1 and .class3
  • ~ is general sibling selector, so all siblings of it get selected
  • Note: pseudo-class have one colon, pseudo-elements have two colons
  • :focus the element focused on
  • :hover the element hovered over
  • :root the top element with no parent
  • :first/last-child the first or last child (duh)
  • :empty any element with no children
  • :only-child any element that has no siblings
  • :nth-child the nth child
  • ::marker allows you to customize markers for unordered lists
  • ::first-letter/first-line styles first line or first letter
  • ::selection lets you change the selection styles
  • ::before/after adds content before or after content
  • lots more!

Attribute selectors also exist: use [attribute] to select any element with that attribute (such as href or src etc)

You can chain with selectors or specify value as well (i.e. img[src] or [src="jfdkfjkdjak.jpg"])

When specifying values, you can be more general:

  • = specifies strings based on value
  • ^= specifies strings from the start
  • $= specifies strings from the end
  • *= specifies strings that contain
  • There's a whole bunch of other interesting ways to specify to reference

Positioning

Five types of positioning:

  • Static - default mode
  • Relative - like default, but can manipulate top/bottom/right/left, and also different for absolute
  • Absolute - removes from the document flow and positions absolutely using top/bottom/right/left from first non-static parent (which is where relative comes in handy) or to html if none exist
  • Fixed - similar to absolute, except positions relative to viewport instead of element, so stays in place when you scroll
  • Sticky - mix between relative and fixed: normally relative, but when you scroll enough it can stay in place as if it was fixed

CSS Functions

CSS comes with a bunch of built in functions that are useful (but we can't create our own)

  • rgb(r, g, b) - calculates a color
  • linear-gradient() - makes a gradient
  • calc() - lets you calculate things... one useful example is size of main, but many others
  • min() - returns lowest of a set of values
  • max() - returns greatest of a set of values
  • clamp() - takes three parameters, a min, a scaling, and a max value, then returns the scaling value clamped in between min and max
  • Lots more!

Custom Properties

We can't define our own functions, but we can define our own variables!

Use the double hyphen (--) to declare a custom property with same naming conventions as usual: case sensitive, hyphen separated (--like-this, --not like this)

Evaluated through the var function, which can also take a fallback value

Scope exists, so if we define it in a selector only that selector and any descendents can access it

So usually we define them in :root, which is basically html but more specific, as everything is a descendent of :root

We can use this to create themes, and even look at preexisting preferences of the user through @media (prefers-color-scheme: ...) etc

Forms

Form Basics

The form element takes two attributes:

  1. action - takes a url value which tells where the data should be taken to be processed (learn more about that later)
  2. method - tells which HTTP request method the browser should do

Some common methods: GET retrieves from server, and POST changes something on server

There are many form controls to customize a form:

  • Input: very useful, allows user to directly input basically anything, specified with a type argument (i.e. text)... also takes placeholder attribute to specify a placeholder
  • Labels: attach text descriptions to something, specified with for... when label associated with input or another thing is clicked, it will auto focus on the speficied element
  • Name attribute: this is part of input, but super important: need a name attribute, essentially a variable name to describe the input to backend where it's being sent or it will be useless
  • Many others...

Lots of different input types, like text, email, password, number, date
