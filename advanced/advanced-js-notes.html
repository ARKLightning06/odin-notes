SVG

SVG: Scalable Vector Graphics

They're great, very scalable so you can zoom in and out pretty much infinitely without loosing resolution, but not great for complex image types

Goes directly into html under the <svg> tag, with several properties:

Property Description Example Use
xmnls 'XML NameSpace,'' specifies dialect Used to make svgs not fall apart, also render some borders
viewBox Defines bounds of SVG, plus aspect ratio, plus origin Used for determining what to show of the SVG
class, id Allows targeting of elements with css or js Used for css styling and javascript manipulating
Other There're a lot of other elements to work with Use elements like circle, path, rect, text to shape the SVG (self explanatory, circle makes circle, path draws a path between points, etc)

For embedding SVGs, can link it or embed it in inline directly... linking is cleaner, but inline has more potential

Tables

Tables are exactly what they sound like

Element Description
th table head cell
tr table row
td table data
tf table foot cell
thead table header
tbody table body
tfooter table footer
colgroup groups columns
col part of colgroup
rowspan how many rows a cell spans
colspan how many columns a cell spans
